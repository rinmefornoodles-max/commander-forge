# Commander Forge 6.0 Alpha 3.1

## Fixed
- Predefined Tokens no longer crashes the app.
- Restored the missing `predefinedTokenMatches()` helper used by the token browser.
- Search supports multiple terms.
- Creature / Artifact / Other filters work for normal and double-faced token definitions.
- Runtime tool errors no longer replace the entire table with the startup-error screen after Forge has successfully loaded.
- The startup watchdog now stops once the main app has rendered successfully.

## Deployment
Upload every file in the GitHub Upload ZIP to the repository root and replace `index.html`.
