# Commander Forge 5.34.2 — Test Override / Sandbox

- Adds a visible Test Override section to every selected card when enabled.
- Force a card to either battlefield, owner hand/graveyard/exile, stack, or library top/bottom.
- Test Override moves bypass mana, timing, land-play and ordinary zone restrictions.
- Mutate can be tested without paying its mutate cost while preserving structural mutate target rules.
- Auras can be test-cast without paying while still requiring an attachment target.
- When phase advancement is blocked, Test Override can explicitly advance anyway.
- Settings includes an Enable Test Override / sandbox controls toggle (on by default).
- Online games still restrict card manipulation to the local player's permitted cards, and Undo still requires opponent approval.
