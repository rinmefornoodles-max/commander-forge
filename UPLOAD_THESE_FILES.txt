THE COMMANDER FORGE 5.20 — REVEALED LIBRARY + TITLE FLOW

Upload these four files to the TOP LEVEL of the GitHub repository:

- index.html
- commander-forge-5.20.0.js
- commander-forge-5.20.0.css
- sw.js

Allow index.html and sw.js to replace the existing versions. Both online players must use 5.20.

REVEALED LIBRARY CARDS
- Private Look now has a separate Reveal to opponent toggle on each viewed card.
- Reveal is independent from Top, Bottom, or Hand destination.
- The opponent can open the revealing player’s Library and see every currently revealed card.
- If a revealed library card moves into hand, it remains visible as Known in hand.
- Revealed opponent cards can be clicked and expanded in the normal right-side inspector.
- The revealed-card inspector is read-only. Hidden opponent cards still cannot be selected.
- Shuffling clears currently revealed library identities.

TITLE SCREEN
- Solo Practice opens solo setup.
- Host Online Game creates a host room and invite code.
- Join Game uses the invite-code field directly from the title screen.
- The redundant Deck Lab button was removed because it led to the same setup workflow.
- Continue Game appears only for an actually started saved game.
