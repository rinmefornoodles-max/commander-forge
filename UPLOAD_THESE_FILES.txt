THE COMMANDER FORGE 5.21

Upload these four website files to the TOP LEVEL of your GitHub repository:

- index.html
- commander-forge-5.21.0.js
- commander-forge-5.21.0.css
- sw.js

Allow index.html and sw.js to replace the existing versions.
Both online players must use version 5.21.0.

CHANGES
- Restores the cleaner title screen with two main choices: Solo Practice and Online Multiplayer.
- Removes Deck Lab and the direct Host/Join controls from the title screen.
- Solo Practice opens only the local two-player deck setup.
- Online Multiplayer opens only the host/join connection setup.
- The redundant Solo/Online tabs are removed from the setup window.
- Adds a Main menu button before a game starts.
- Adds Create Treasure to Table Tools / Settings.
- The Treasure is a proper artifact token with: {T}, Sacrifice this artifact: Add one mana of any color.
- In online play, Create Treasure always creates it for the local player.
- In solo play, it creates it for the active player.

AFTER UPLOADING
1. Commit to main.
2. Wait for GitHub Pages to turn green.
3. Open the site in a new Incognito/Private tab first.
