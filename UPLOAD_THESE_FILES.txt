THE COMMANDER FORGE 5.3 — TABLETOP UX UPDATE

Upload these four website files to the TOP LEVEL of your GitHub repository:

- index.html
- commander-forge-5.3.0.js
- commander-forge-5.3.0.css
- sw.js

Allow index.html and sw.js to replace the existing versions.
The versioned JS and CSS files can remain beside older versions.

After committing to main:
1. Wait for the GitHub Pages action to turn green.
2. Open the website in an Incognito/Private tab first.
3. Hard-refresh or clear the site's stored data if an older version remains.

- Mirrored opponent/player utility areas.
- Cleaner life and poison controls with no overflow.
- Drag Equipment or Auras from the battlefield onto a valid permanent.
- Attached cards display as selectable mini cards on the equipped creature.
- Custom token frame, accent, and text colors.
