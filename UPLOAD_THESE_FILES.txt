THE COMMANDER FORGE 5.8

Upload these four website files to the TOP LEVEL of your GitHub repository:

- index.html
- commander-forge-5.8.0.js
- commander-forge-5.8.0.css
- sw.js

Allow index.html and sw.js to replace the existing versions.
Commit to main and wait for GitHub Pages to deploy.

Changes:
- Each battlefield is divided into two horizontal lanes.
- Creatures and all other nonland permanents render in the upper lane.
- Lands render automatically in the lower lane.
- Both lanes remain valid battlefield drag-and-drop targets.
- Equipment, Auras, tapping, counters, tokens, and coach analysis continue using the same underlying cards.
