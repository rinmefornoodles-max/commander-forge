THE COMMANDER FORGE 5.14 — TOKEN CLEANUP

Upload these four files to the TOP LEVEL of your GitHub repository:

- index.html
- commander-forge-5.14.0.js
- commander-forge-5.14.0.css
- sw.js

Allow index.html and sw.js to replace the existing versions.
Commit to main and wait for GitHub Pages to deploy.

Changes:
- Tokens no longer remain in hand, graveyard, exile, library, command, or stack.
- Token dies records a death/zone-change event, queues recognized death or leave triggers, then removes the token.
- Remove token cleanly makes a token cease to exist without treating it as dying.
- Dragging a token to graveyard automatically uses Token dies.
- Dragging a token to another nonbattlefield zone automatically removes it.
- Normal nontoken cards keep all existing zone actions.
