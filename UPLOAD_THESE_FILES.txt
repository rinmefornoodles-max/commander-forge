VOID WINNOWER CAST TEST
1. Put Void Winnower under Player 1's control.
2. On Player 2/the bot, try to cast a spell with mana value 2, 4, or 6.
3. Forge should reject it before payment/casting.
4. Try an odd-mana-value spell. It should remain legal if no other rule forbids it.
5. Test a zero-mana-value spell: it should also be prohibited.

VOID WINNOWER BLOCK TEST
1. Attack the player who controls an opponent's Void Winnower.
2. Try to block with a creature whose mana value is even.
3. Forge should refuse the block.
4. Try an odd-mana-value creature that otherwise blocks legally.
5. It should be allowed.

BOT TEST
1. Put Void Winnower under your control.
2. Give the bot a mix of even- and odd-mana-value spells.
3. It should stop trying to cast the even ones.
4. Attack the bot while it controls even- and odd-mana-value creatures.
5. It should only consider legal odd-mana-value blockers.

Select Void Winnower in Card Actions and look at Oracle Compiler status.
It should list both the static casting and static blocking restriction.
