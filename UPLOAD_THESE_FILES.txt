COACH FIXES
- Opening the Coach panel no longer performs the full tactical search in the background.
- Analyze runs cooperatively and yields back to the browser throughout move generation and Monte Carlo sampling.
- Crowded boards automatically use a smaller candidate/sample budget instead of locking the page.
- Normal boards still use the selected coach sample setting when practical.
- Duplicate Analyze presses cannot start overlapping searches.
- The loading window shows progress and includes a Stop analysis button.
- Card-rule parsing is cached during each simulated state, greatly reducing repeated keyword and Oracle-text work.
- Hidden library placeholders share a compact simulation representation; private card identities remain hidden.
- Exact mana payment planning uses bounded search inside the coach while normal gameplay payment remains unchanged.
- Partial results are clearly labeled when analysis reaches its responsiveness time limit.

AFTER UPLOADING
1. Commit the files to main.
2. Wait for the GitHub Pages action to turn green.
3. Close old Commander Forge tabs.
4. Open the updated site in a new Incognito/Private tab first.
5. For multiplayer, both players should use the same 5.17.0 version and create a new room.
