THE COMMANDER FORGE — TACTICAL COACH BASE 5.0

1. Extract this ZIP.
2. Open the main Code page of your GitHub commander-forge repository.
3. Choose Add file -> Upload files.
4. Drag EVERYTHING inside the extracted folder into the repository.
5. Allow matching files to be replaced.
6. Commit directly to main.
7. Open Actions and wait for Deploy The Commander Forge to turn green.
8. Hard-refresh the website or clear its stored site data.

This is a complete synchronized build. Do not upload only coach.js or rules.js.

A correct deployment runs:
- Build same-origin official precon catalog
- Run trainer and coach tests
- Deploy website

The package includes the .github workflow, existing precon fixes, playmat,
custom decks, public memory, auto-mana, and the new tactical coach engine.
